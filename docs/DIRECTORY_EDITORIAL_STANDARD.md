# Directory editorial standard

## Eligible destinations

Every public Yehaw service must use its official canonical HTTPS destination. Editors must verify ownership and relevance before publication.

## Prohibited destinations

Do not publish URL shorteners, mirror sites, unofficial APK downloads, credential-collection pages, copied brand pages, or affiliate redirects. Any approved sponsored placement must be clearly disclosed and must not alter the user’s intended destination.

## Required metadata

Before publication, each record requires:

- Active status
- Verified status
- Verification date
- Last-reviewed date
- Official canonical HTTPS URL
- Correct category and display order
- Accurate concise description

## Reporting and review

User reports for broken links, incorrect destinations, or security concerns enter a moderation queue. Editors must investigate promptly, update/deactivate unsafe listings, and preserve an audit trail for editorial changes.

## Sponsorship

Sponsored placement must be visually and textually disclosed. Sponsorship does not waive destination-verification requirements.
